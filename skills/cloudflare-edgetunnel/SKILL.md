# Cloudflare EdgeTunnel

交付用户自己的实例或已验证的客户端配置。先判断任务是新部署、接手已有实例、仅筛选节点，还是更新订阅；只执行用户要求的分支。账号、域名、认证信息和节点参数均以本次实例为准。

## 前置条件

先从用户指定的账户、已登录会话和已有配置中确认信息。仅在缺失事项阻塞当前动作时引导用户处理；等待时继续与其无关的已授权工作。

- **账户与登录**：部署或维护 Cloudflare 资源前，核对用户指定的账号及权限。未登录时，引导用户在指定浏览器的 Cloudflare 官方登录页自行登录；验证码、二次验证和邮箱验证由用户完成。验证会话后再操作。多个账号不能由邮箱猜测授权。已有实例参数且只做本地测速时，不要求重新登录 Cloudflare。
- **部署资源与认证**：新部署默认独立 Pages Direct Upload 和 KV；先检查账号、项目名、现有资源和费用。`ADMIN` 由用户在 Cloudflare 页面自行设置或输入；管理页未登录时引导用户本人登录。不在聊天索要密码、API token 或订阅凭据。需要 CLI/API 时，用用户本地提供的最小权限凭据；不得从浏览器存储提取会话。
- **上传与工具**：文件上传受浏览器权限阻塞时，引导用户查看扩展的文件访问权限并刷新页面；仍失败时，可让用户在已打开的上传页面选择已准备的包。缺少客户端或兼容核心时，先检查本机现有工具；用户同意或任务已授权时，再采用合适的安装或替代方式。不要假定应用内核可独立运行。
- **节点与网络**：从目标实例取得实际协议、UUID、SNI、WebSocket Host/path 和端口；缺少参数时，引导用户访问实例管理页或提供私密配置。测速前检查物理网卡、TUN、候选来源与测试目标；无法证明物理出口时，停止把结果作为本地宽带排名。密码和订阅链接保密。
- **选择与交付**：沿用用户指定的客户端、地区、数量、测速门槛和交付方式。未指定时，本用户的优选偏好是日本、新加坡、美国各 3 个，不含香港；每候选测 10 次，以 10 次全成功的算术平均值排序。其他用户或新指令可以覆盖这些偏好。项目默认使用 `pages.dev`；自定义域名和付费资源不自行购买或迁移。

## 按任务执行

1. **部署或接手**：读取 [references/deployment.md](references/deployment.md)。核对账号及已有资源；固定并检查当前上游版本，创建或接手目标项目。验证部署、管理入口和真实代理请求。仅更新节点时保留已有项目、KV 和认证信息。部署成功不等于代理验收通过。
2. **本地优选或替换节点**：读取 [references/measurement.md](references/measurement.md)。以实际物理出口和真实代理 URL Test 测量候选，记录所有样本、失败、平均值和最大值；分别核验入口、普通目标和 Cloudflare 目标所见地区。候选来源的标签或旧测速不等于当前结果；未满要求或失败时报告缺额与最佳实测候选，不声称全网最低。
3. **客户端配置**：从本实例参数生成或更新独立 Clash/Mihomo YAML。保留协议、认证、SNI、WS Host/path、实际端口与 TLS 校验；更新手动选择与自动测速组，排除用户明确不要的节点。语法检查后，按用户授权导入；只有用户要求启用时才切换现有选择。改节点地址不等于创建独立用户或撤销已分享凭据。
4. **在线订阅**：仅在用户要求生成、托管或更新时，读取 [references/subscription.md](references/subscription.md)。定位正确账号和现有来源，保护订阅凭据；核验线上内容、访问控制及客户端同步。筛选节点不自动授权发布或修改已有部署。

报告实际完成范围、实例资源和版本、测速网络与时间、节点 IP:端口及原始结果、失败和未验证事项。仅在用户授权的私密交付渠道提供订阅链接；持有链接者可能取得代理凭据。保持原配置或回退入口可用，清理自己启动的临时核心和含密钥文件。
